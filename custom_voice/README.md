# 🎙️ 专属音色克隆录入指南

OpenScreen Studio 支持每位同事录入并使用自己的真实声音为软件教程配音。

---

## 🚀 3 步录入你的专属声音

### 1. 录制一段 10~15 秒的自然人声
* **设备建议**：使用手机自带录音机（iPhone 录音机效果极佳，可在设置中开启“无损压缩”）；
* **环境要求**：找一个安静房间，避开风扇与回声，嘴巴距离麦克风 15~20 厘米；
* **朗读建议**：语速保持平稳、自信（推荐语速约 4.0 ~ 4.5 字/秒），朗读一段你熟悉的产品讲解词。

### 2. 放入本目录
将你的录音文件命名并存放到 `custom_voice/` 目录下（推荐 `.wav` 格式，24kHz 或 48kHz）。

### 3. 配置 `voices.json`
在 `custom_voice/voices.json` 中追加你的配置项，例如：

```json
[
  {
    "id": "my_voice",
    "name": "你的名字 (专属原声)",
    "role": "产品经理 / 业务专家",
    "tag": "F5-TTS · 专属音色",
    "ref_audio": "my_recording.wav",
    "ref_text": "录音中所朗读的完整准确文字内容。"
  }
]
```

### 4. 刷新工作台
重启或刷新 OpenScreen Studio，在 **STAGE 2 解说音色与语速校准** 中即可直接看到你的专属音色卡片！点击出片，全自动使用你的原声朗读并压制 Apple 风格黑底字幕！
